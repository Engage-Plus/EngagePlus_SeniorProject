# Bison Campus Compass

There's a site for Howard University called bison engage https://howard.campuslabs.com/engage/. We want to create an app called engage+ that adds to this and gives the opportunity to actual engage with the organizations and have the chance to filter events and find exactly what events they would like to. here is the rtm.
